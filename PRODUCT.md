# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React + Vite + strict TypeScript + Tailwind CSS, npm. Static Vercel deployment. The owner explicitly chose React and rejected Next.js.

## Users

Recruiters, collaborators, and clients who want to understand Sahil's engineering work quickly. Terminal fluency is not assumed; every important action must also be available through visible controls.

## Product Purpose

Present Sahil Halday007 as a software and AI/ML engineer in Tanzania, and make his work in accessible educational technology, full-stack software, and hardware-connected experiences easy to inspect and discuss.

## Positioning

A real browser-based terminal workspace is the navigation and interaction model, not a terminal-themed landing page. The workspace makes technical work explorable while preserving readable content and conventional controls.

## Operating Context

- One static, client-rendered React application deployed to Vercel.
- The user may arrive on a phone with no terminal experience, reduced-motion enabled, JavaScript disabled, or Supabase unavailable.
- The cat counter uses Africa/Dar_es_Salaam server-day boundaries when Supabase is configured; a clearly labeled local counter is the offline/unconfigured fallback.

## Capabilities and Constraints

- Six windows: Home (`whoami`), About, Projects, Stack, Experience Log, and Contact.
- Terminal commands, vim-like modes, keyboard navigation, command palette, theme switching, and cat interaction enhance but do not gate ordinary navigation.
- Seven palettes: Tokyo Night, Gruvbox Dark, Catppuccin Mocha, Nord, Phosphor, Amber, and a light terminal theme.
- The seven project stories are SensePlay, SenseLink, SensePlay Analytics Engine, TOIO website development, Fablab Management System, Computer Vision Projects, and AR Experiential Marketing.
- Unknown links, dates, and other factual details remain TODOs in a typed content file; never invent outcomes or metrics.
- No accounts, analytics trackers, or hosted contact-form service.

## Brand Commitments

- Terminal culture is the interaction language: tmux, vim, lazygit, btop, k9s, box-drawing, command prompts, status lines, and pane boundaries.
- Use JetBrains Mono only; terminal themes are the color system.
- Avoid fake macOS chrome, Matrix rain, emoji, low-contrast hacker-green styling outside the Phosphor theme, and terminal interactions that block recruiters.
- Keep voice concise, grounded, and human.

## Evidence on Hand

- Public repositories: `senseplay_analytics_engine`, `toio_games`, `fablab-management-system`, `TOIO-Edugame`, `Geospatial-AR`, `quiz_generator`, and `OpenCV_game_development`.
- The public profile README verifies Sahil's role context, technology groupings, public email `sahil@toio.or.tz`, and GitHub account `SahilHalday007`.
- `fablab-management-system` is the public repository backing the Fablab inventory, costing, job, and statistics story; precise claims must stay within repository evidence.
- No public SenseLink, Robotek Labs, TOIO website source, computer-vision, or AR experience repository was supplied in the inspected public repo list. The owner's brief is the source for those descriptions; public links remain TODO.
- LinkedIn URL, CV URL, and experience dates were not supplied; expose typed TODOs rather than placeholders that look like working links.

## Product Principles

1. Explain the work in ten seconds without requiring terminal knowledge.
2. Keep every interaction available through keyboard, touch, and visible controls where applicable.
3. Treat accessibility and local context as product requirements, not polish.
4. Connect software to real learning and physical interaction without overstating outcomes.
5. Use only claims that can be traced to the owner's brief or public evidence.

## Accessibility & Inclusion

- Minimum 14px text on phones, keyboard-operable controls, visible focus, WCAG AA semantic text in all themes, reduced-motion support, and no horizontal overflow.
- Keep core text accessible when JavaScript is unavailable; no boot or typing effect may delay it.
