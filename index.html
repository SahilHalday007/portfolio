AI × DATA × EDTECHFEAT.01

SensePlay Analytics Engine

Educational games produce a constant stream of raw gameplay events. The engine turns that stream into useful insight: session metrics, progress measures, and AI-assisted narrative reports that educators can actually read.

APPROACH A Python service architecture: FastAPI endpoints ingest gameplay events, PostgreSQL stores them with pgvector for semantic search over session patterns, while Celery and Redis run asynchronous report jobs and Groq drafts AI-assisted narrative summaries. Alembic manages the schema; the repo ships tests and project documentation.

  • Python
  • FastAPI
  • PostgreSQL
  • pgvector
  • Celery
  • Redis
  • Groq
  • Alembic
github ↗

Built as part of the SensePlay learning-through-play work: an inclusive platform for children practising memory, attention, reasoning, sequencing and reaction skills. AI reporting is used to explain patterns, not to replace educator judgement or make clinical claims.

AI EXPERIMENT × TOOLING06

PDF-to-Quiz Generator

A small Streamlit tool that extracts text from a PDF and generates multiple-choice quiz questions from the key terms it finds. A study-aid experiment.

APPROACH PyPDF2 pulls the text layer, scikit-learn's TF-IDF scores rank the most significant terms, and questions are built around them and saved as JSON. An experiment: extraction depends on the PDF having a real text layer. Scanned documents won't work.

how_i_build.txt

  1. Start with the user and environment. Good solutions account for accessibility, connectivity, available devices, language, and context.
  2. Treat accessibility as a design constraint from day one. Input options and clear feedback should be considered early, not tacked on at the end.
  3. Connect design to engineering. Interaction details, loading states, error handling, and maintainable architecture all matter.
  4. Use AI with a purpose: useful analysis and assistance, with clear limits and human judgement in the loop.
  5. Build, test, learn, improve. Practical prototypes, real feedback, and steadily hardening the parts that prove useful.
